Este repositório contém todos os projetos, exercícios e atividades de cursos que ja fiz.

## Cursos Incluídos

### 1. CS50X: Introduction to Computer Science
Uma introdução às bases intelectuais da ciência da computação e da arte da programação.
* **Linguagens:** C, Python, SQL, HTML, CSS e JavaScript.
* **Tópicos:** Algoritmos, Estruturas de Dados, Gestão de Memória, Segurança e Desenvolvimento Web.

### 2. CS50P: Introduction to Programming with Python
Focado especificamente no design e implementação de soluções utilizando a linguagem Python.
* **Tópicos:** Funções, Variáveis, Condicionais, Ciclos, Exceções, Bibliotecas, Testes Unitários, I/O de Ficheiros, Expressões Regulares e Programação Orientada a Objetos (OOP).
